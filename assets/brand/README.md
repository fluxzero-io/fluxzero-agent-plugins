# Fluxzero plugin icon

`fluxzero.png` is the unchanged 512 × 512 transparent website icon from
`fluxzero-io/fluxzero-site`, path
`public/assets/fluxzero/icons/light-blue-v1/android-chrome-512x512.png`.
Source commit: `13e54a1944acd5006f94f4197be855da94334c01`.
The website's icon gradient uses `#3582BC` and `#78B4D6`; these are also the
plugin's light and dark theme accent colors.

Keep this source asset in the repository. `npm run generate` copies it into
the Codex, Claude and Cursor packages so subdirectory installations do not
depend on files outside their package root.
